# XP Interface

<Recipe id="landsutilities:xp_interface" />

The XP Interface acts like a fluid tank specifically for fluid XP. It can accept fluid XP from virtually any mod, though extracting fluid XP defaults to this mod's by default.

Can be upgraded using a tiered Capacity Upgrade.

Right-clicking the XP Interface also opens a GUI to not only view the amount of fluid XP stored, but also to transfer the XP to or from the player.
