# Auto Anvil

<Recipe id="landsutilities:auto_anvil" />

The Auto-Anvil, true to its name, is an anvil that can have items automatically input to it and will automatically process items at the cost of fluid XP from any mod (20mB = 1 experience point). There is no internal fluid XP tank; instead fluid XP is taken from an adjacent tank in a given direction (above the anvil by default).
