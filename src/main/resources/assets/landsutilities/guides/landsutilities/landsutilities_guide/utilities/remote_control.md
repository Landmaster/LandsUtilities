# Remote Control

<Recipe id="landsutilities:remote_control" />

The Remote Control lets you remotely access the menu of a selected block in range (in fact, more generically right-click on it). Shift-right-click on a block to add it to the remote control. Shift-scroll to cycle between blocks. Right-click the remote control to open that block's menu.

Type /landsutilities rename_link &lt;name&gt; as a command to rename what the current block connection is called, and /landsutilities delete_link to delete the current block from the remote control.

By default, up to 5 blocks can be stored in the remote control. This can be increased by the Remote Control Capacity enchantment, by 5 for each level. Also, the remote control range can be increased by the Remote Control Range enchantment. Levels 1 and 2 multiply the range by 20 and 1000 respectively. Level 3 gives infinite range.
