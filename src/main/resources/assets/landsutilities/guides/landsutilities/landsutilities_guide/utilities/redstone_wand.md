# Redstone Wand

<Recipe id="landsutilities:redstone_wand" />

The Redstone Wand can be used to force a block at a selected position to effectively act like a redstone block, lever, or button. Shift-scroll to cycle between modes. Shift-right-click to add or remove the desired redstone capability to the block.
