# Interfacer

<Recipe id="landsutilities:block_interfacer" />

The Interfacer simulates a left/right click (with the given item in the single inventory slot if applicable). This runs continuously, though a redstone signal can be used to control the interfacer if redstone control is configured in the GUI.
