# Facade Wand

<Recipe id="landsutilities:facade_wand" />

The Facade Wand can be used to disguise a block as another block (any block with a standard model works), useful for cable facades. Shift-right-click on a block to set the block to disguise things as. Right-click on a block to disguise it as the set disguise.
